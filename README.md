# Portfólio de Adalberto Velloso

Site de portfólio pessoal desenvolvido na disciplina de desenvolvimento web. A página apresenta quem sou, meus contatos, formação, habilidades, competências, objetivos profissionais e uma seção de projetos.

O site é responsivo, tem tema em vermelho e branco, menu de navegação com rolagem suave entre as seções e um botão de voltar ao topo.

## Tecnologias utilizadas

- **HTML5**: estrutura e conteúdo da página
- **CSS3**: estilização, cores e layout
- **JavaScript**: interações simples (botões de projetos e voltar ao topo)
- **Git e GitHub**: versionamento e hospedagem do código

## Estrutura do projeto

```
portfolio/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── script.js
└── README.md
```

## Como visualizar

1. Clone o repositório:
   ```
   git clone https://github.com/adalqv/adalqv.github.io.git
   ```
2. Abra o arquivo `index.html` em qualquer navegador.
